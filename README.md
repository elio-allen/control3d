# control3d
Control your 3D printer with a controller using the Gamepad module.
  
This was specifically made for the RepRap Mendel90 paired with the Logitech Saitek Flight Yoke, so beware.  
Make sure to run ```setup.sh``` so the right USB device is used. If it doesnt work, modify /dev/3dprinter to what ever /dev/ your printer is on.
